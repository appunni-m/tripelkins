# Licensing and third-party notices

## Project licensing status

The repository does not currently contain a project license for Tripelkins code
or artwork. No open-source license for those materials is granted here. The
owner must select project and contribution terms; licenses belonging to
components do not license the surrounding game.

## Component notices

The production build includes [Credits & licenses](https://appunni-m.github.io/tripelkins/credits.html),
linked from Options → Advanced. Its source is
[`public/credits.html`](public/credits.html).

- Browser library notices are generated from installed dependency packages into
  `public/licenses/dependencies.txt`.
- Rust dependency notices are generated from the locked Cargo dependency closure
  into `public/licenses/rust-dependencies.txt`, including build-time packages.
- ONNX Runtime binary notices, font licenses, Whisper's implementation license
  and their provenance URLs live in [`public/licenses/`](public/licenses/).
- Optional model and conversion authors, model cards and service links appear
  in the credits page. These are separate components with separate terms.

[`scripts/prepare-notices.mjs`](scripts/prepare-notices.mjs) runs during both dev
and production preparation. Generated notice files are ignored by Git and copied
into `dist/licenses/`; build prerequisites are in [Contributing](CONTRIBUTING.md).
Model weights are fetched after player consent, not committed in the repository.

Creature art, scenery and effects are generated by project code; sounds are
synthesized. The favicon is a project-authored SVG with ICO and PNG derivatives.
That describes the asset pipeline, not legal clearance. Outstanding human review
is recorded in the [release checklist](docs/RELEASE_CHECKLIST.md).
