Deployment checks

These checks use this deployed site's real workers and runtime files. They don't read or change your colony. Speech checks use a recording you choose below. The file stays on your device; the microphone is never opened.

Running every model check can use about 2 GB of internet data and browser storage. Metered data charges may apply. Clicking a model check or Run all approves its downloads. Models run one at a time and each worker is released afterward. Downloads remain in the same browser caches used by the game. Clearing those caches, storage eviction, or changed files can require a new download. Site & storage does not download models.

Download resume transfers one Laya model file (about 53 MB) into a disposable cache. It interrupts at a saved checkpoint, resumes in a fresh worker, checks the complete file's SHA-256, then removes the test cache. It does not initialize a model. The transfer comes from the same model host used by the game; data charges may apply.

The 25-resident audit runs five simulated minutes in a disposable colony, with independence accepted and births held to keep the comparison at 25. It uses cached Laya GPU weights only, reports actual model choices and each resident's work and movement, and never loads your saved colony. Stone milestone starts with the river crossed and no player command; it must quarry and refine 300 blocks. Whisper cached restart uses two fresh workers with downloads disabled. Choose the recording below to check transcription; without one it checks inference on silence only.

Recording for speech checks

Record yourself saying “Hello little friends. Please keep everyone happy and healthy.” Choose a recording up to 15 seconds and 4 MB that you have permission to use. Without a file, speech checks are marked skipped before loading a model.
